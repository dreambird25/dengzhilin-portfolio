# 关于我

我是 **邓智林**，专注于跨境电商业务系统、Amazon 平台集成和工程化实践。

我更关心软件能否在真实环境中长期运转：外部 API 是否可恢复、任务是否可追踪、数据是否能安全迁移、一次改动是否能被验证。这些问题往往比“接口能不能调通”更重要。

## 我在解决什么

- 面向 Amazon 业务，将店铺、Listing、订单、库存、FBA、广告和运营分析组织成清晰的 ERP 能力。
- 在 SP-API、Ads API 等不完全可靠的外部系统前，设计限流、重试、窗口重叠、状态同步与故障恢复。
- 用类型检查、Flyway 迁移、自动化测试和部署门禁，让系统随业务增长仍保持可维护。

## 常用技术

Java 21、Spring Boot、Spring Cloud、Vue 3、TypeScript、Vite、MySQL、Redis、RabbitMQ、Nacos、Flyway、Vitest。

## 工作方式

我把 AI 当作研发流程中的加速器：帮助拆解问题、生成候选方案和补齐测试；最终的架构判断、边界设计与上线验证仍由工程方法兜底。
