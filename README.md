# dengzhilin.fun

邓智林的个人技术网站，展示正在构建的思帆科技亚马逊运营系统（SF Amazon ERP）、技术写作与联系入口。

## 技术栈

- VitePress（基于 Vue 3 + Vite）
- TypeScript
- Vitest
- Markdown 内容管理

## 本地开发

```bash
pnpm install
pnpm dev
```

## 验证与构建

```bash
pnpm test
pnpm build
pnpm preview
```

生产域名预设为 `https://dengzhilin.fun`；部署前请在托管平台配置该域名与 HTTPS。
